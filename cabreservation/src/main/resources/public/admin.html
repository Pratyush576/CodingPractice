Cab Reservation Admin

Admin Token

Not a real security boundary — a shared dev secret (CABRESERVATION_ADMIN_TOKEN, defaults to dev-admin-token), same "not a production security model" spirit as the rider/driver auth elsewhere in this app.

Platform Stats

Rolling windows (last 24h / 7d / 30d from now), not calendar boundaries — the server has no notion of your timezone to anchor a calendar day to. Applies to every panel below.

Trip Outcomes

Financials

"Revenue" and "Driver payouts" are what actually settled (CHARGED/PAID only). "Fare value" is the gross fare across every completed trip regardless of charge outcome — the gap between it and Revenue, together with Declined charges, is what surfaces silent collection failures instead of hiding them inside one number.

All Requests

Every trip request platform-wide within the window above, with its financial outcome — filtered further by status and/or a text search below, both applied client-side over that same list.
